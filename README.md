# Factory Homepage (GitHub Pages + Google Sheets)

PT. Komitrando Emporio B2B site.
페이지는 GitHub에서 열고, 글/제품/인증은 구글 시트에서 수정합니다.

## 1. 구글 시트 공유 (필수)

홈페이지가 시트를 읽으려면 **로그인 없이** 볼 수 있어야 합니다.

1. 구글 시트 열기
2. 오른쪽 위 **공유**
3. 일반 액세스: **링크가 있는 모든 사용자**
4. 역할: **뷰어**
5. 완료

시트 주소:
https://docs.google.com/spreadsheets/d/1EYfHAB759ecLMpC1D6tQVsXSa6yHLIkJazQJ7gFZ-ws/edit

## 2. GitHub Pages 켜기

1. https://github.com/ahnpro119/factory-homepage
2. Settings → Pages
3. Branch: `main` / folder: `/ (root)`
4. Save
5. 1~2분 후 주소:
   https://ahnpro119.github.io/factory-homepage/

## 3. 일상 수정

- 제품, 소개, 인증, CSR → **구글 시트만 수정** 후 홈페이지 새로고침
- 디자인/코드 → 이 GitHub 저장소 파일 수정

문의 폼은 1차에서 이메일 링크로 연결했습니다.
나중에 Google Form으로 바꿀 수 있습니다.
