## Chrome address bar "주의 요함"

Cause: HTTP still serves www. GitHub Pages Enforce HTTPS was not on.
HTTP `komitrando.com` redirected to `http://www.komitrando.com` (200), not https.
SSL itself is valid Let's Encrypt for apex + www until 2026-12-07.

Fix later / user action: Pages settings → Enforce HTTPS.
Share only https://www.komitrando.com

## 1. Photos missing on mobile 4G

Likely ImageURL host, not layout.
- Google Drive preview links often fail on cellular
- Imgur can be slow or blocked on some ID carriers
- Large files time out
- Opening the site over http can block https images

Next direction when coding:
- Do not use raw Drive links as card images
- Prefer small card files (about 200-400KB)
- Host on a path that works on ID 4G (same GitHub repo or a stable CDN)

## 2. Card size and extra margin differ on phone vs iPad

Cards use full column width and a fixed 280px image height with object-fit contain.
- Phone portrait: 1 column, narrow + 280px tall
- iPad / landscape: 2 columns, wider + still 280px tall
Box aspect changes per device, so contain creates new empty bands even after padding was removed.

Next direction when coding:
- Force product image stage to 1:1 on every breakpoint
- Keep contain inside that square

## 3. Video play on two-up grids

Phone portrait (1 card per row): mid-screen autoplay feels natural.
iPad or phone landscape (2 cards per row): only one video plays because play is limited to a single card.
Looks broken when two photos sit side by side and only one moves.

Preferred fix later:
- Portrait phone: keep scroll autoplay
- Two-up (iPad / landscape): no autoplay; play only the tapped card
Rejected for now: play both muted, or force one column on iPad
